This directory contains PDF files:
- biochar_production.pdf       (ICAR manual on biochar)
- briquette_manual.pdf         (MNRE biomass briquetting guide)
- mushroom_substrate.pdf       (Mushroom cultivation from agro-waste)

These are actual PDF files you download from:
- ICAR: https://icar.org.in/publications
- MNRE: https://mnre.gov.in/biomass
- Place them in this directory, then run: python -m app.rag.indexer
